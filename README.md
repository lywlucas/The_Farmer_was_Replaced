# README

这个目录存放本人在游戏 **《编程农场》** 中编写和使用的代码。
其中 'snaky2.py' 曾于2026.8获得恐龙排行榜20名

## 文件说明

| 文件 | 用途 |
| --- | --- |
| `move` | 基础移动相关代码。 |
| `snaky` | 用于解决恐龙化石问题的代码。 |
| `snaky2` | 恐龙化石问题的改进版代码。 |
| `leaderboard` | 用于挑战排行榜的代码。 |
| `__builtins__.py` | 游戏提供的内置解释文件，用于了解可用的内置功能。 |

## 说明

- 这些代码面向《编程农场》的游戏内运行环境，可能无法直接在标准 Python 环境中运行。
- `__builtins__.py` 为游戏内置文件，仅作参考，不建议随意修改。
- 代码会随着游戏进度和解题思路持续更新。

## 使用方式

将相应文件中的代码复制或导入到游戏编辑器中运行。
